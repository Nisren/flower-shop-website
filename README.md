# Paris Flowers 🌸

Paris Flowers is a responsive front-end flower shop website built with HTML, CSS, Bootstrap, and JavaScript.

## Features

- Responsive navigation bar
- Product listing page
- Product search
- Product filters
- Product details page
- Shopping cart page
- Add, remove, and update product quantity
- Cart data saved using localStorage
- Login/Register UI
- Toast notifications
- Modern responsive design

## Technologies Used

- HTML5
- CSS3
- Bootstrap
- JavaScript
- Font Awesome
- Google Fonts
- localStorage

## Pages

- `website_template.html` — Home page
- `index.html` — Shop page
- `product.html` — Product details page
- `cart.html` — Shopping cart page
- `login1a.html` — Login page
- `registration1a.html` — Register page
